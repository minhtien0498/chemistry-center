# Chemistry Center 

Trang web Trung tâm Hóa học - React + Ant Design

## Cài đặt

```bash
npm install
```

## Chạy ứng dụng

```bash
npm start
```

Sau đó truy cập http://localhost:3000 để xem trang web.

## Thư mục chính
- `src/` - Mã nguồn React
- `public/` - Tài nguyên tĩnh

## Công nghệ sử dụng
- React
- Ant Design
